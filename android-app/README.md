## تغییر به حالت آنلاین (اختیاری)
اگر بعداً وب‌اپ را روی هاست دپلوی کردید و خواستید اپ به سرور وصل شود، در
`java/ir/homeiotnt/modirman/MainActivity.java`:

```java
private static final String START_URL = OFFLINE_URL;   // حال فعلی (آفلاین)
// private static final String START_URL = ONLINE_URL; // حالت آنلاین
```

و آدرس `ONLINE_URL` را تغییر دهید، سپس دوباره بسازید.

## ساخت مجدد APK
پیش‌نیاز: JDK 17+ (یا فقط JRE + فایل `ecj.jar` کنار SDK) و build-tools 34 + platform android-34

```bash
export ANDROID_SDK=/path/to/android-sdk    # مسیر SDK
bash android-app/build.sh
```

خروجی: `android-app/modirman-v1.1.apk`

## ⚠️ نکته خیلی مهم — keystore
- فایل `keystore/modirman.keystore` را **گم نکنید**!
- کافه‌بازار برای هر بروزرسانی، امضای APK را با نسخه قبل مقایسه می‌کند؛
  اگر keystore عوض شود بروزرسانی رد می‌شود.
- این keystore در ریپو عمومی است با رمز ساده؛ **قبل از انتشار تجاری جدی**،
  یک keystore جدید با رمز قوی بسازید و آن را در جای امن (خارج از گیت‌هاب) نگه دارید.

## محدودیت‌ها و نکات
- داده‌ها در localStorage WebView ذخیره می‌شود (حدود ~۵ مگابایت ≈ ده‌ها رسید تصویری فشرده) —
  اگر حجم پر شد، چند رسید قدیمی را حذف کنید
- داده هر دستگاه جدا است (آفلاین است دیگر!) — برای همگام‌سازی بین چند گوشی،
  حالت آنلاین + هاست لازم است
- نوتیفیکیشن سیستم‌عامل واقعی (اپ بسته) نیاز به FCM دارد؛ الان هشدار درون‌برنامه‌ای دارید
- رمزها روی خود دستگاه ذخیره می‌شوند (اپ تک‌کاربره-محلی است)
