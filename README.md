# 🏢 مدیرمن | مدیریت هوشمند ساختمان

اپلیکیشن مدیریت ساختمان با رابط کاربری فارسی و راست‌چین — ساخته‌شده با Next.js 16، TypeScript، Tailwind CSS و shadcn/ui.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 📱 **ثبت‌نام با شماره موبایل** | هر کس ابتدا با شماره موبایل خود حساب می‌سازد؛ مدیر سپس با جستجوی همان شماره او را به ساختمان اضافه می‌کند |
| ⏳ **صفحه انتظار عضویت** | کاربر ثبت‌نام‌شده تا زمان تأیید مدیر، صفحه «در انتظار تأیید» می‌بیند |
| 👑 **انتقال مدیریت** | مدیر می‌تواند با یک تأیید، مدیریت ساختمان را به هر عضو منتقل کند (مدیر قبلی خودکار ساکن می‌شود) |
| 🛡️ **سطح دسترسی** | دو نقش **مدیر** و **ساکن**؛ عملیات مدیریتی فقط برای مدیر |
| 🗓 **تقویم شمسی و یادآوری** | تقویم جلالی با ثبت رویداد و یادآوری **شخصی** یا **کل ساختمان** |
| 🔔 **نوتیفیکیشن گوشی** | در زمان یادآوری، نوتیفیکیشن سیستم‌عامل نمایش داده می‌شود (Notification API + Service Worker) |
| 🧾 **قبض‌ها و شارژ** | ثبت قبض ماهانه توسط مدیر، مشاهده و پرداخت توسط ساکن |
| 💳 **شماره کارت و شبا** | مدیر اطلاعات پرداخت را در تنظیمات ثبت می‌کند؛ ساکن با یک دکمه کپی می‌کند |
| 📸 **رسید پرداخت** | ساکن عکس رسید واریز را آپلود می‌کند؛ مدیر تأیید/رد می‌کند و تأیید رسید، قبض را پرداخت‌شده می‌کند |
| 📢 **اعلان‌ها** | انتشار اطلاعیه‌های ساختمان توسط مدیر |
| 🔧 **درخواست تعمیرات** | ثبت و پیگیری درخواست‌های ساکنین |
| 📊 **داشبورد** | آمار ساکنین، قبض‌های معوق، رسیدهای در انتظار تأیید و بدهی واحد |
| 👤 **پروفایل** | ویرایش نام/موبایل/طبقه و تغییر رمز عبور |
| 🔑 **بازنشانی رمز عضو** | اگر ساکنی رمزش را فراموش کرد، مدیر یک رمز موقت ۶ رقمی برایش می‌سازد |
| 📲 **PWA** | نصب روی گوشی با آیکون اختصاصی «مدیرمن» و پشتیبانی آفلاین سبک |

### حساب‌های آزمایشی (داده اولیه — رمز همه: `1234`)
| نقش | شماره موبایل |
|---|---|
| مدیر ساختمان | `09121111111` |
| ساکن واحد ۸ | `09122222222` |
| ساکنین نمونه | `09124440001` تا `09124440005` |
| تازه ثبت‌نام‌شده (در انتظار تأیید) | `09123333333` |

> 🔐 رمزها با **scrypt** هش می‌شوند، ورود با **rate limit** (۵ تلاش در ۱۵ دقیقه) محافظت می‌شود و توکن‌ها JWT (HMAC-SHA256) با انقضای ۱۸۰ روزه هستند.

- 🌐 اگر خواستید اپ به هاست وصل شود (چند دستگاه همزمان)، در `MainActivity.java` حالت آنلاین را فعال کنید (راهنما: [`android-app/README.md`](android-app/README.md))

### 🤖 دانلود APK با GitHub Actions (ساخت خودکار)

این پروژه یک **workflow آماده** دارد که با هر تغییر در سورس اندروید، APK را روی سرورهای گیت‌هاب **کامپایل، امضا و منتشر** می‌کند:

**روش ۱ — از تب Actions (خروجی هر اجرا):**
1. وارد ریپو شوید → تب **Actions** را باز کنید
2. روی «**ساخت APK مدیرمن**» کلیک کنید
3. آخرین اجرا (تیک سبز ✅) را باز کنید
4. پایین صفحه، بخش **Artifacts** → فایل `modirman-apk-…` را دانلود کنید
5. ZIP را باز کنید؛ فایل `modirman-v1.1.apk` داخل آن است

**روش ۲ — از ریلیز `latest` (دانلود مستقیم، ساده‌ترین):**
- آدرس زیر همیشه **آخرین APK ساخته‌شده توسط Actions** را می‌دهد:
  **`https://github.com/Hosseinnemati/modirman/releases/latest`**
- یا لینک مستقیم فایل: `https://github.com/Hosseinnemati/modirman/releases/download/latest/modirman-v1.1.apk`

**روش ۳ — اجرای دستی ساخت:**
- تب Actions → «ساخت APK مدیرمن» → دکمه **Run workflow** → **Run workflow**
- پس از ~۲ دقیقه، خروجی در همان اجرا (Artifacts) و در ریلیز `latest` قرار می‌گیرد

> 💡 هر بار سورس اپ (`android-app/`) تغییر کند و push شود، APK جدید خودکار ساخته می‌شود — نیازی به Android Studio یا کامپیوتر شخصی نیست.

## 🚀 اجرای محلی (Local)

پیش‌نیازها: [Node.js 20+](https://nodejs.org) و [Bun](https://bun.sh) (یا npm/pnpm)

```bash
# ۱) نصب وابستگی‌ها
bun install        # یا: npm install

# ۲) ساخت دیتابیس (SQLite + Prisma)
bun run db:push    # یا: npx prisma db push

# ۳) (اختیاری) ساخت داده نمونه
bun prisma/seed.ts

# ۴) اجرای سرور توسعه
bun run dev        # http://localhost:3000
```

دیتابیس از فایل `db/custom.db` استفاده می‌کند (SQLite — نیازی به سرور دیتابیس نیست).

## 📲 انتشار در کافه‌بازار (Bazaar)

کافه‌بازار فقط فایل **APK اندروید** می‌پذیرد. این پروژه یک **وب‌اپلیکیشن** است؛ پس باید آن را روی اینترنت هاست کنید و سپس یک APK از نوع WebView بسازید. مراحل کامل:

### مرحله ۱ — هاست کردن وب‌اپ
اپ باید روی یک آدرس اینترنتی (HTTPS) در دسترس باشد. گزینه‌ها:

- **سرور مجازی ایرانی** (پیشنهادی برای کاربران ایران): Liara، Parspack، ابرآروان — پلن Node.js با دیسک، اجرای `bun run build && bun run start`
- **Vercel / Netlify**: رایگان، اما SQLite روی آن ماندگار نیست؛ باید دیتابیس را تغییر دهید یا از Turso استفاده کنید
- بعد از هاست، آدرسی مثل `https://modirman.example.ir` خواهید داشت

### مرحله ۲ — ساخت APK از نوع WebView
> 💡 **خبر خوب:** APK آماده و امضاشده در پوشه [`apk/`](apk/) همین ریپو موجود است و سورس کامل آن هم در [`android-app/`](android-app/) قرار دارد — نیازی به انجام مراحل زیر نیست مگر بخواهید تغییراتی بدهید. راهنمای اختصاصی: [`android-app/README.md`](android-app/README.md)

**سریع‌ترین روش (Android Studio):**
1. [Android Studio](https://developer.android.com/studio) را نصب کنید
2. پروژه جدید با قالب **Empty Views Activity** بسازید
3. آیکون آماده اپ در `public/images/` است (`icon-512.png`) — هنگام ساخت پروژه از آن استفاده کنید
4. در `activity_main.xml` یک `WebView` تمام‌صفحه بگذارید و در `MainActivity.java` آدرس سایت را لود کنید:
   ```java
   WebView webView = findViewById(R.id.webview);
   webView.getSettings().setJavaScriptEnabled(true);
   webView.getSettings().setDomStorageEnabled(true);
   webView.setWebChromeClient(new WebChromeClient());
   webView.loadUrl("https://YOUR-APP-URL.ir");
   ```
5. در `AndroidManifest.xml` مجوز اینترنت و نوتیفیکیشن را اضافه کنید:
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   <uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
   ```
6. **Build → Generate Signed App Bundle / APK** → یک keystore بسازید (نگه‌دارید! برای همه بروزرسانی‌ها لازم است) → خروجی **APK release**

**روش جایگزین (Capacitor):**
```bash
npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "مدیرمن" ir.modirman.app --web-dir=public
# در capacitor.config.json قسمت server مقدار url را آدرس سایت بگذارید
npx cap add android
npx cap open android   # سپس از Android Studio خروجی APK بگیرید
```

### مرحله ۳ — ثبت‌نام در پنل توسعه‌دهندگان بازار
1. به [developers.cafebazaar.ir](https://developers.cafebazaar.ir) بروید و در **پنل توسعه‌دهندگان** ثبت‌نام کنید
2. احراز هویت / تصاحب حساب را با مدارک هویتی انجام دهید (اجباری برای انتشار)
3. اطلاعات مالی را برای دریافت درآمد تکمیل کنید

### مرحله ۴ — ثبت برنامه
1. در پنل: **افزودن برنامه** → اندروید
2. فایل **APK امضاشده** را آپلود کنید
3. اطلاعات فارسی را کامل کنید:
   - نام برنامه: **مدیرمن**
   - توضیح کوتاه و کامل
   - دسته‌بندی: «ابزارها» یا «سبک زندگی»
   - **حداقل ۲ اسکرین‌شات** (از همین اپ با موبایل بگیرید: داشبورد، تقویم، قبض‌ها)
   - آیکون ۵۱۲×۵۱۲ (آماده: `public/images/icon-512.png`)
   - **آدرس سیاست حفظ حریم خصوصی** (یک صفحه ساده HTML که بگوید داده‌ها کجا ذخیره می‌شود)
4. وضعیت انتشار: رایگان
5. **ارسال برای بررسی** — کارشناسان بازار معمولاً طی چند روز نتیجه را اعلام می‌کنند

### ✅ نکات مهم برای تأیید شدن در بازار
- نام و توضیحات نباید برند دیگران را شامل باشد
- اپ نباید کرش کند — قبل از آپلود، APK را روی چند دستگاه واقعی تست کنید
- محتوای اپ باید با توضیحات مطابقت داشته باشد
- اگر پرداخت درون‌برنامه‌ای ندارید (مثل این اپ)، نیازی به SDK بازار نیست؛ فقط برای در-app billing لازم می‌شود

## 🗂 ساختار پروژه
```
prisma/schema.prisma      # مدل‌ها: User, Reminder, Bill, Receipt, Announcement, ServiceRequest, Building
src/app/api/              # API: auth (login/register/me), residents, members/search, reminders,
                          #      profile, bills, receipts, announcements, requests, settings, stats
src/components/app/       # UI: ورود/ثبت‌نام، داشبورد، تقویم، قبض‌ها، رسیدها، ساکنین، اعلان‌ها
src/lib/                  # auth (توکن/هش)، validation، rate-limit، jalali، notifications، api-client
public/                   # manifest.webmanifest، sw.js و آیکون‌های اپ (images/)
docs/HOST-GUIDE.md        # راهنمای ذخیره داده روی هاست شخصی (cPanel + PHP + MySQL)
db/custom.db              # دیتابیس SQLite
```

## 🔒 امنیت (قبل از استفاده واقعی)

- بکاپ دوره‌ای فایل دیتابیس را فراموش نکنید
